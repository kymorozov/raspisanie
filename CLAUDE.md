# raspisanie — контекст для Claude Code

> Читается в начале каждой сессии. Текущее состояние — `NOTES.md`.

## Что за проект

Школьное расписание и домашние задания на одной странице. Сайт:
<https://kymorozov.github.io/raspisanie/> (GitHub Pages из ветки `main`, корень).

- `index.html` — вся страница.
- `data/*.json` — домашние задания (МЭШ, ручные, отметки «сделано»).
- `hw/` — фото заданий с листочка.
- `scripts/mesh-sync.mjs` — выгрузка заданий из МЭШ.
- `mac/` — фоновая синхронизация с МЭШ на MacBook (`install.sh` ставит,
  `update.sh` обновляет). Пишет в репозиторий через GitHub API, поэтому в
  истории много автоматических коммитов «МЭШ: …».

## Как запустить

Открыть `index.html` в браузере (или любой статический сервер в корне).

## Как деплоится

Автоматически: любой push в `main` → GitHub Pages обновляет сайт за 1–2 минуты.

## Договорённости

- **Репозиторий публичный** (бесплатный GitHub Pages требует публичный).
  Никаких токенов, паролей и личных данных сверх необходимого в файлах.
  Токены МЭШ и GitHub живут только в
  `~/Library/Application Support/raspisanie/config.json` на Mac.
- Начало сессии — `git pull` (робот на Mac коммитит постоянно). Конец —
  обновить `NOTES.md`, commit, push.
- Окончания строк — LF (`.gitattributes`).
- Пользователь — не программист: объяснять простыми словами, спрашивать
  подтверждение перед необратимыми действиями.
